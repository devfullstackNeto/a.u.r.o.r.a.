# Artigo base

> **Estado documental:** protótipo funcional digital. A pulseira física não foi construída nem testada. Dados da demonstração são sintéticos; registros de piloto nesta versão permanecem apenas no navegador e não constituem, por si, avaliação institucional realizada.

Título proposto: Prototipagem digital de uma interface educacional local para alfabetização funcional. Resumo, fundamentação, método, implementação, avaliação técnica, limites e próximos passos devem ser preenchidos com fontes e resultados verificados antes de submissão.

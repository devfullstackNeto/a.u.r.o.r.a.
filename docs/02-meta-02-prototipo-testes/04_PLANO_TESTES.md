# Plano de testes do protótipo digital

> **Estado documental:** protótipo funcional digital. A pulseira física não foi construída nem testada. Dados da demonstração são sintéticos; registros de piloto nesta versão permanecem apenas no navegador e não constituem, por si, avaliação institucional realizada.

Executar `npm run typecheck`, `npm run test`, `npm run build` e `npm run test:e2e`. Verificar entrada textual, resposta correta e incorreta, conclusão, consentimento, SUS, segregação de dados, persistência, responsividade e uso offline. Registrar ambiente, saída e artefatos.

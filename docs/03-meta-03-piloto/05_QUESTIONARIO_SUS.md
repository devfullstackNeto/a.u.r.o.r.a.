# Questionário SUS

> **Estado documental:** protótipo funcional digital. A pulseira física não foi construída nem testada. Dados da demonstração são sintéticos; registros de piloto nesta versão permanecem apenas no navegador e não constituem, por si, avaliação institucional realizada.

A interface usa os dez itens da System Usability Scale, em escala de 1 (discordo totalmente) a 5 (concordo totalmente). O questionário é opcional e aparece **após** o feedback geral. Sua pontuação não é mostrada à participante; aparece apenas no painel e na exportação específica.

| Item | Afirmação apresentada |
|---|---|
| 1 | Eu gostaria de usar este sistema com frequência. |
| 2 | Achei o sistema desnecessariamente complexo. |
| 3 | Achei o sistema fácil de usar. |
| 4 | Eu precisaria de ajuda de alguém para usar este sistema. |
| 5 | Achei que as funções deste sistema estavam bem integradas. |
| 6 | Achei que havia muita inconsistência neste sistema. |
| 7 | Imagino que a maioria das pessoas aprenderia a usar este sistema rapidamente. |
| 8 | Achei o sistema complicado de usar. |
| 9 | Senti confiança ao usar o sistema. |
| 10 | Precisei aprender muitas coisas antes de conseguir usar o sistema. |

Dez respostas são obrigatórias **somente quando a participante optar por SUS**. O cálculo e as restrições de interpretação estão em `METODO_CALCULO_SUS.md`.
